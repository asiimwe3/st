# St. Peters Medical Center — Website

Official website for **St. Peters Medical Center**, Kyenjojo Town, Kagadi Road, Uganda.

## Tech Stack
- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Deployment:** Vercel / Netlify

## Pages
- `/` — Home
- `/about` — About Us
- `/services` — Medical Services
- `/doctors` — Our Doctors
- `/appointment` — Book Appointment
- `/contact` — Contact & Location

## Local Development
```bash
npm install
npm run dev
```
